## 🌟 About AES 2026

The **Alpha Entrepreneurship Summit (AES 2026)** is a 3-day business and startup event for students, hosted at **Alpha College Karachi** from **November 13 to November 15, 2026**.

Delegates take part in practical business simulations, attend keynotes by industry leaders, and pitch their startup ideas to experienced judges.

## 🛡️ Architecture & Security Fortifications

The AES platform is engineered for enterprise-grade speed, strict compliance, and defense against automated attacks:

- **Next.js 16.4.2 + Turbopack**: Fully patched against recent Next.js advisories (`GHSA-2464-fhr4-w9xw`, `GHSA-p3m5-59mp-jv5r`, `GHSA-673q-mjm6-r5xr`).
- **HTTP Security Headers**: Enforced via `proxy.js` and `next.config.mjs`:
  - `Content-Security-Policy`: Strict directives allowing only vetted CDNs and Google Fonts while disabling `object-src` and untrusted scripts.
  - `X-Frame-Options: DENY`: Complete clickjacking protection.
  - `X-Content-Type-Options: nosniff`: Prevents MIME-type confusion attacks.
  - `Strict-Transport-Security (HSTS)`: 2-year duration with subdomains and preload.
  - `Permissions-Policy`: Restricts camera, microphone, geolocation, and USB APIs.
- **Active Scanner Mitigation**: Next.js proxy instantly returns **HTTP 403 Forbidden** for directory traversal attempts and vulnerability scanners probing for `.env`, `.git`, `wp-admin`, or PHP scripts.
- **Vulnerability Disclosure (RFC 9116)**: Standardized [`/.well-known/security.txt`](https://alphaace.com.pk/.well-known/security.txt) endpoint for responsible reporting.
- **Search Engine & LLM Crawlers**:
  - Dynamic [`sitemap.xml`](https://alphaace.com.pk/sitemap.xml) with automatic last-modified timestamps.
  - Dynamic [`robots.txt`](https://alphaace.com.pk/robots.txt) + standalone [`robots.xml`](https://alphaace.com.pk/robots.xml).
  - Machine-readable [`/llms.txt`](https://alphaace.com.pk/llms.txt) and [`/llms-full.txt`](https://alphaace.com.pk/llms-full.txt) tailored for AI discovery agents.
  - Dynamic branded 1200×630 OpenGraph card at `/opengraph-image`.
  - Schema.org `BusinessEvent` JSON-LD rich snippet markup.

## 🛠️ Local Development

### Prerequisites
- **Node.js**: `v20.x` or `v22.x` recommended
- **npm**: `v10.x` or higher

### 1. Clone the repository
```bash
git clone https://github.com/ACE-Society-IT/aes.git
cd aes
```

### 2. Install dependencies
```bash
npm install
```

### 3. Setup environment variables
```bash
cp .env.example .env.local
```

### 4. Run development server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 5. Production build test
```bash
npm run build
npm start
```
